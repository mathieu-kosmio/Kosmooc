Question d'accroche : qu'est-ce qui change vraiment le résultat quand on précise sa demande ?

| Ce qu'on voit | Ce qu'on dit |
|---|---|
| Écran : le devis DEV-2026-0412 à gauche, trois conversations vides à droite. Titre : « Trois demandes, un même devis ». | Qu'est-ce qui change vraiment le résultat quand on précise sa demande ? Pour le voir, nous allons mener une expérience simple sur un même devis, celui de la Menuiserie des Landes, une entreprise fictive. |
| Écran : demande A en grand : « Fais-moi une fiche de production avec ce devis. » | Demande A, la demande brute, telle qu'on l'écrit spontanément : « Fais-moi une fiche de production avec ce devis. » Voilà ce que beaucoup font au début. |
| Écran : demande B : « À partir de ce devis, extrais les informations nécessaires à la production. N'invente rien. » | Demande B : on ajoute la source et l'interdiction d'inventer. « À partir de ce devis, extrais les informations nécessaires à la production. N'invente rien. » Deux ajouts, trois secondes d'écriture. |
| Écran : demande C avec les blocs rôle, contexte, champs, règles, données manquantes, format. | Demande C : on ajoute un rôle, le contexte de l'entreprise, les champs attendus dans un ordre fixé, les règles de contrôle, la gestion des données manquantes, et le format final avec une liste de points à vérifier avant lancement. |
| Écran : trois conversations ouvertes dans trois fenêtres distinctes. | Attention à la méthode. Ouvrez une conversation neuve pour chaque demande, sinon l'historique fausse la comparaison. Utilisez le même devis. Et n'améliorez pas les réponses pendant le test : on observe l'écart. |
| Écran : grille de comparaison, cinq lignes, trois colonnes. | Comparez selon cinq critères : exactitude, omissions, inventions, lisibilité, facilité de contrôle. Regardez par exemple si la remise commerciale est recopiée sur la fiche, si les abréviations sont devinées, si les unités sont changées. |
| Écran : un surlignage sur les ajouts de C qui ont changé la réponse. | La question utile : qu'est-ce qui a réellement amélioré le résultat, plus que la beauté de la réponse ? Souvent, ce sont les contraintes et le signalement des informations manquantes. |
| Écran : « Exercice : 20 minutes ». Liens vers le devis et le gabarit. | Consigne : téléchargez le devis et le gabarit dans les ressources du module, lancez A, B puis C, remplissez la grille, et gardez la demande C. Elle deviendra votre prompt métier. |
