Carte de titre : « M2 · savoir demander », « Trois demandes, trois résultats », « Académie PerfIA · 2 min ».

| Ce qu'on voit | Ce qu'on dit |
|---|---|
| L'expérience : « Trois demandes, un même devis ». document : Devis DEV-2026-0412, étiquette « Entreprise fictive ». cartes : Demande A, Demande B, Demande C. | Qu'est-ce qui change vraiment le résultat quand on précise sa demande ? Pour le voir, nous allons mener une expérience simple sur un même devis, celui de la Menuiserie des Landes, une entreprise fictive. |
| Demande a : « La demande brute ». zone de saisie : « Fais-moi une fiche de production avec ce devis. ». | Demande A, la demande brute, telle qu'on l'écrit spontanément : Fais-moi une fiche de production avec ce devis. Voilà ce que beaucoup font au début. |
| Demande b : « Deux ajouts à la demande ». pastilles : La source : ce devis, L'interdiction d'inventer. zone de saisie : « À partir de ce devis, extrais les informations nécessaires à la production. N'invente rien. ». | Demande B : on ajoute la source et l'interdiction d'inventer. À partir de ce devis, extrais les informations nécessaires à la production. N'invente rien. Deux ajouts, trois secondes d'écriture. |
| Demande c : « La demande complète ». cartes : Un rôle, Contexte de l'entreprise, Champs attendus, ordre fixé, Règles de contrôle, Données manquantes, Points à vérifier. | Demande C : on ajoute un rôle, le contexte de l'entreprise, les champs attendus dans un ordre fixé, les règles de contrôle, la gestion des données manquantes, et le format final avec une liste de points à vérifier avant lancement. |
| La méthode : « Une comparaison honnête ». liste : Une conversation neuve par demande, Le même devis, Rien d'amélioré pendant le test. | Attention à la méthode. Ouvrez une conversation neuve pour chaque demande, sinon l'historique fausse la comparaison. Utilisez le même devis. Et n'améliorez pas les réponses pendant le test : on observe l'écart. |
| La grille : « Cinq critères de comparaison ». cartes : Exactitude, Omissions, Inventions, Lisibilité, Facilité de contrôle. pastilles : Remise recopiée ?, Abréviations devinées ?, Unités changées ?. | Comparez selon cinq critères : exactitude, omissions, inventions, lisibilité, facilité de contrôle. Regardez par exemple si la remise commerciale est recopiée sur la fiche, si les abréviations sont devinées, si les unités sont changées. |
| Ce qui compte : « Ce qui améliore vraiment le résultat ». citation : « Qu'est-ce qui a réellement amélioré le résultat ? ». pastilles : Les contraintes, Le signalement des manques. | La question utile : qu'est-ce qui a réellement amélioré le résultat, plus que la beauté de la réponse ? Souvent, ce sont les contraintes et le signalement des informations manquantes. |
| Votre exercice : « Vingt minutes pour comparer A, B et C ». étapes : Télécharger devis et gabarit, Lancer A, B puis C, Remplir la grille, Garder la demande C. citation : « La demande C vous resservira ». | Téléchargez le devis et le gabarit dans les ressources du module, lancez A, B puis C, remplissez la grille, et gardez la demande C : elle vous resservira pour toutes vos demandes importantes. |
