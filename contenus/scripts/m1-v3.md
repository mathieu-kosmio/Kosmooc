Question d'accroche : à quelles tâches pouvez-vous faire confiance à une IA, et lesquelles faut-il toujours vérifier ?

| Ce qu'on voit | Ce qu'on dit |
|---|---|
| Écran : trois colonnes vides, vert, orange, rouge. Titre : « À quoi faire confiance ? » | À quelles tâches pouvez-vous faire confiance à une IA, et lesquelles faut-il toujours vérifier ? Voici trois familles pour vous repérer. |
| Colonne verte qui se remplit : extraire, synthétiser, comparer, classer, rédiger, transformer. | Très adapté : extraire des informations d'un document, synthétiser, comparer, classer, rédiger de façon structurée, transformer un document d'un format à un autre. Le tri de vos mails par projet entre dans cette famille. |
| Colonne orange : calculs critiques, références réglementaires, informations absentes, ambiguïtés. | À contrôler : les calculs critiques, comme un nombre de pièces à débiter à partir d'un linéaire. Les références réglementaires, un numéro d'article ou une norme. Les informations absentes du document. Les interprétations ambiguës. |
| Colonne rouge : décision engageante, validation automatique, données sensibles. | À éviter sans cadre : prendre seule une décision qui engage l'entreprise, valider automatiquement la qualité, ou transmettre des données sensibles sans avoir vérifié les règles applicables. |
| Écran : un devis où le délai est absent, l'IA écrit « semaine 12 ». | Le piège le plus courant : l'IA comble les trous. Un délai manque ? Elle en propose un plausible. Une abréviation est inconnue ? Elle la devine. Un calcul ne tombe pas juste ? Elle l'arrondit. |
| Écran : la consigne « Si une information est absente, écris information absente. N'invente rien. » | Le bon réflexe : lui demander de signaler ce qu'elle ignore. Écrivez : « Si une information est absente du document, écris information absente. » Vous lirez des absences au lieu d'inventions plausibles. |
| Écran : balance « coût de l'erreur » et « niveau de contrôle ». | Retenez la règle : plus une erreur coûte cher, plus le contrôle doit être explicite. Consigne : classez huit tâches de votre entreprise dans ces trois familles, puis passez le quiz. |
