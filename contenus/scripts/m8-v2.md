Question d'accroche : si votre fournisseur doublait ses prix demain, pourriez-vous changer d'outil en une demi-journée ?

| Ce qu'on voit | Ce qu'on dit |
|---|---|
| Écran : un fournisseur avec une étiquette de prix qui double. | Si votre fournisseur doublait ses prix demain, pourriez-vous changer d'outil en une demi-journée ? La réponse dépend de ce que vous avez construit autour de lui. |
| Écran : un bateau et six ancres : données, conditions, localisation, prix, modèles retirés, formats propriétaires. | Six dépendances à repérer. Les données : sont-elles exportables ? Les conditions d'utilisation : elles peuvent changer. La localisation : où sont traitées vos données ? Le prix. Les modèles retirés : un prompt réglé sur un modèle peut se comporter autrement sur le suivant. Et les formats propriétaires. |
| Écran : un assistant enfermé dans une boîte « Interface du fournisseur ». | Un assistant paramétré uniquement dans l'interface d'un fournisseur ne se déménage pas. C'est une dépendance. |
| Écran : un dossier de fichiers texte : prompt, règles, gabarit, cas de test, journal. | À l'inverse, votre prompt métier, vos règles, vos gabarits, vos cas de test et votre journal de corrections sont du texte. C'est votre harnais, il vous appartient. |
| Écran : le dossier se glisse d'un outil A vers un outil B. | Changer d'outil revient alors à recoller ce fichier dans un autre projet et à rejouer vos cas de test. Le harnais réduit la dépendance. |
| Écran : un modèle qui est retiré, le dossier de tests qui se rejoue. | Si le fournisseur remplace un modèle, rejouez vos cas de test. Vous voyez tout de suite ce qui a changé. |
| Écran : trois options côte à côte : fournisseur européen, modèle ouvert auto-hébergé, accompagnement de déploiement. | Si vos exigences portent sur la localisation ou la maîtrise des données, plusieurs voies existent. Un fournisseur européen. Un modèle ouvert hébergé chez vous ou chez un hébergeur de votre choix, avec des coûts de serveur et de maintenance. Ou un accompagnement de déploiement : Kosmio en propose un, comme d'autres prestataires. À comparer selon votre budget et vos compétences. |
| Écran : la grille de huit questions, avec oui, non, en partie. | Consigne pour vous : remplissez la grille d'autodiagnostic en huit questions. Pour chaque non ou en partie, notez une action concrète. Puis écrivez l'outil que vous gardez et la date de réexamen. |
