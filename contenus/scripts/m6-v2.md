Question d'accroche : votre prototype marche sur l'exemple avec lequel vous l'avez construit. Marchera-t-il sur le suivant ?

| Ce qu'on voit | Ce qu'on dit |
|---|---|
| Écran : un prototype qui réussit sur un document, un second document inconnu qui arrive. | Votre prototype marche sur l'exemple avec lequel vous l'avez construit. Marchera-t-il sur le suivant ? C'est la vraie question, et c'est le sujet de cette vidéo. |
| Écran : la grille E-T-S-C à gauche, six blocs à droite, des flèches entre les deux. | D'abord, le prompt métier. C'est la grille E-T-S-C rendue exécutable, en six blocs : rôle, mission, sources, règles, sortie, contrôle. |
| Écran : les blocs se remplissent avec l'exemple de la Menuiserie des Landes. | La mission reprend la Transformation, les sources reprennent l'Entrée, la sortie reprend la Sortie, le contrôle reprend le Contrôle. Le rôle et les règles reprennent ce que vous avez appris au module 2. Rien de nouveau, sinon que la consigne devient un fichier que l'on relit et que l'on corrige. |
| Écran : un tableau en trois colonnes : vocabulaire, exceptions, critères de qualité. | Ce que l'outil ne peut pas deviner, c'est votre métier. Vocabulaire : vos abréviations. Exceptions : le bois vert, le traitement sur un seul repère. Critères de qualité : ce qu'est une bonne fiche pour votre chef de production. Chaque ligne devient une règle. |
| Écran : un second devis arrive, une ligne « idem essence ci-dessus » surlignée. | Vient le test décisif. Prenez un second document, représentatif mais différent. Dans notre cas, un devis court avec une ligne piège : idem essence ci-dessus. |
| Écran : un bouton « Lancer » et un cadenas sur les règles. | Lancez sans toucher aux règles. Pas de retouche en cours de route, sinon vous ne testez plus le prototype, vous le réajustez. |
| Écran : un tableau avec champs corrects, erreurs, informations manquantes, temps gagné estimé. | Mesurez : combien de champs corrects, combien d'erreurs, ce que l'outil a signalé comme manquant, et le temps gagné, estimé avec prudence. |
| Écran : quatre étiquettes : règle manquante, donnée absente, cas particulier, erreur de l'IA. | Classez chaque écart. Règle manquante : vous pouvez l'écrire. Donnée absente : le document ne la contient pas. Cas particulier : une exception rare. Erreur de l'IA : elle a mal lu ou inventé. |
| Écran : trois pastilles : utilisable, à améliorer, à re-spécifier. | Puis décidez : utilisable, à améliorer, ou à re-spécifier. Re-spécifier est une réponse tout à fait légitime : cela veut dire que le cadrage de départ était trop flou. |
| Écran : le prompt et le tableau côte à côte. | Consigne pour vous : écrivez votre prompt en six blocs, testez-le sur un document jamais vu, remplissez le tableau et notez votre décision en deux lignes. |
