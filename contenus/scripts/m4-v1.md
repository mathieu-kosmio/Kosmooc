Question d'accroche : pourriez-vous décrire, étape par étape, comment un devis accepté devient une fabrication dans votre entreprise ?

| Ce qu'on voit | Ce qu'on dit |
|---|---|
| Écran : une feuille blanche, un feutre, un point d'interrogation. | Pourriez-vous décrire, étape par étape, comment un devis accepté devient une fabrication dans votre entreprise ? Si c'est difficile, c'est normal. Un processus que personne n'a décrit ne peut pas être confié à un outil. |
| Écran : un paperboard avec cinq colonnes vides : déclencheur, entrées, étapes, décisions, sorties. | Pour le décrire, cinq éléments suffisent. Le déclencheur, les entrées, les étapes, les décisions et les sorties. Vous allez les remplir en dessinant de gauche à droite. |
| Écran : la colonne « Déclencheur » se remplit : « Le client accepte le devis ». | Le déclencheur : qu'est-ce qui lance le processus ? Un devis accepté, un mail, un dossier de consultation reçu. |
| Écran : la colonne « Entrées » : devis, plan, mail, références. | Les entrées : les documents et les informations qui arrivent. Un devis, parfois un plan, un mail du client. |
| Écran : la colonne « Étapes » avec des prénoms sur chaque étape. | Les étapes : qui fait quoi, dans quel ordre. Mettez un prénom sur chaque étape. Vous découvrirez des ressaisies faites par habitude, ou une information que seule une personne connaît. |
| Écran : la colonne « Décisions » avec trois losanges. | Les décisions : où faut-il interpréter, arbitrer, demander une précision ? Ce sont les endroits où l'automatisation est la plus délicate, donc ceux à regarder de plus près. |
| Écran : la colonne « Sorties » : la fiche de production. | Les sorties : les documents ou décisions produits. Ici, la fiche de production qui lance le débit. |
| Écran : six pastilles : ressaisie, attente, erreur, recherche, oubli, dépendance à une personne. | Une fois le dessin terminé, cherchez les irritants. Ressaisie, attente, erreur, recherche, oubli, dépendance à une personne. Entourez-les sur votre dessin et gardez les trois principaux : ce sont eux qui départagent vos cas d'usage. |
| Écran : un dessin avec trois cercles numérotés 1, 2, 3. | Consigne pour vous : dessinez maintenant le processus de votre cas fil rouge et entourez vos trois irritants. Prévoyez vingt minutes, avec la personne qui fait la tâche au quotidien si possible. |
