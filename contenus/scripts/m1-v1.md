Carte de titre : « Module 1 · comprendre l'IA générative », « Un modèle qui prédit la suite », « Académie PerfIA · 2 min ».

| Ce qu'on voit | Ce qu'on dit |
|---|---|
| La question : « D'où vient la réponse ? ». zone de saisie : « Quelle essence pour « Bastaing DOU » ? ». pastille : « Une grande base de données ? ». | Quand vous posez une question à une IA, d'où vient sa réponse ? Beaucoup pensent qu'elle cherche dans une grande base de données. Ce n'est pas le cas, et comprendre pourquoi change votre façon de l'utiliser. |
| L'entraînement : « Des régularités, pas des documents ». puces : De très grandes quantités de textes, Comment les phrases s'enchaînent, Comment on rédige un devis, Comment on décrit une charpente. | Un modèle de langage a été entraîné sur de très grandes quantités de textes. Il en a retenu des régularités : comment les phrases s'enchaînent, comment on rédige un devis, comment on décrit une charpente. |
| La prédiction : « La suite la plus plausible ». jetons : Bastaing DOU sec 18 % : essence =. citation : « Il prédit ». | Quand vous lui écrivez, il produit la suite la plus plausible, mot après mot, à partir de votre demande et du contexte. Il ne recopie pas un document et il ne consulte pas un annuaire. Il prédit. |
| Ses forces : « Excellent pour transformer du texte ». puces : Reformuler, Résumer, Classer, Extraire, Comparer, Rédiger. encadré : Un devis → les lignes utiles. encadré : Des notes de chantier → un compte rendu. | Résultat : il est excellent pour reformuler, résumer, classer, extraire des informations, comparer, rédiger de façon structurée. Donnez-lui un devis, il en tire les lignes utiles. Donnez-lui des notes de chantier, il en fait un compte rendu. |
| Ses limites : « Il ignore la vérité de votre métier ». puces : DOU ?, CHT ?, Vos essences, Vos tolérances. citation : « Connaissances figées : il n'apprend pas de vos documents ». pastille : « Mémoire : un réglage de votre compte ». | Mais il ne connaît pas, par défaut, la vérité de votre métier. Vos abréviations maison, vos essences, vos tolérances lui sont inconnues. Ses connaissances sont aussi figées : il n'apprend rien de vos documents. Si votre outil semble se souvenir de vous, c'est une fonction de mémoire liée à votre compte, que l'on apprend à régler dans le module Utiliser l'IA de façon fiable. |
| À retenir : « Une réponse fluide peut être fausse ». citation : « La qualité d'écriture n'est pas une preuve d'exactitude ». liste : Lire la section « Le modèle », Vidéo suivante : l'agent et le harnais. | Dernier point, essentiel : une réponse fluide peut être fausse. La qualité d'écriture n'est pas une preuve d'exactitude. Consigne : lisez la section Le modèle du module, puis passez à la vidéo suivante, sur l'agent et le harnais. |
