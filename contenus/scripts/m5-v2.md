Question d'accroche : combien de fois avez-vous recollé le même document dans une nouvelle conversation ?

Préparation de l'enregistrement : on montre la création d'un projet dans deux outils (par exemple Le Chat de Mistral et ChatGPT, ou ceux des abonnements les plus fréquents chez les inscrits). Vérifier le jour même le nom exact de la fonction et l'offre qui la propose. Fichiers prêts : devis DEV-2026-0412 anonymisé, fiche attendue remplie à la main, gabarit vierge, demande C du module 2.

| Ce qu'on voit | Ce qu'on dit |
|---|---|
| Capture : trois conversations dans la barre latérale, le même devis recollé dans chacune. | Combien de fois avez-vous recollé le même document dans une nouvelle conversation ? Dans un simple chat, la matière se perd. Un projet règle ce problème. |
| Capture, premier outil : on clique sur le menu qui crée un projet (ou espace, ou assistant selon l'outil), on le nomme « Fiche de production ». Bulle à l'écran : le nom exact de la fonction et l'offre concernée. | Dans cet outil, la fonction s'appelle [nom exact]. On la trouve ici. On nomme le projet d'après le cas : « Fiche de production ». |
| Capture : on dépose trois fichiers, pas plus : le devis anonymisé, la fiche attendue, le gabarit. | On dépose peu de choses. Un exemple réel anonymisé, la sortie attendue pour cet exemple, le gabarit vierge. Pas tout le disque dur. |
| Capture : on ouvre la zone d'instructions, on colle la demande C, on la découpe en quatre blocs visibles : rôle, mission, sources, règles. | Les instructions tiennent en quatre blocs. On part de la demande C du module 2 : rôle, mission, sources à utiliser, règles. « N'invente rien, signale ce qui manque, conserve les unités, pas de prix. » |
| Capture, second outil : le même parcours en accéléré, en soulignant ce qui diffère (nom de la fonction, emplacement des fichiers, limite de taille ou de nombre de fichiers). | Dans le second outil, c'est le même principe, sous un autre nom. [Commenter les différences réelles constatées le jour de l'enregistrement.] Ce qui compte : vos instructions sont du texte, vous pouvez les recoller ailleurs. |
| Capture : première conversation dans le projet, on demande la fiche pour le devis. La réponse s'affiche, on surligne deux ou trois écarts avec la fiche attendue. | Premier essai. [Commenter le résultat réel.] Il y a des écarts, c'est normal. On ne corrige pas tout de suite : on les note. Au module 6, chaque écart deviendra une règle. |
| Capture : un document texte « constats M5 » avec trois lignes : ce qui marche, ce qui ne va pas, ce que je n'ai pas compris. | Consigne : créez votre projet, déposez votre exemple, écrivez vos instructions, lancez un essai, notez trois lignes. Et apportez-les à la séance collective de mi-parcours. |
