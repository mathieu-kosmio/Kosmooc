Question d'accroche : combien de fois avez-vous recollé le même document dans une nouvelle conversation ?

| Ce qu'on voit | Ce qu'on dit |
|---|---|
| Écran : trois conversations ouvertes, le même devis collé dans chacune. | Combien de fois avez-vous recollé le même document dans une nouvelle conversation ? Dans un simple chat, la matière se perd. Chaque conversation repart de zéro. |
| Écran : une boîte étiquetée « Projet » qui reçoit des documents et des consignes. | Un projet règle ce problème. C'est un espace de l'outil où l'on range les documents de référence et les instructions. Chaque conversation démarre de la même base. |
| Écran : trois marches : conversation, projet, procédure réutilisable. | Voyez trois niveaux. La conversation seule pour un besoin ponctuel. Le projet pour un cas que l'on répète. Et, au module suivant, la procédure réutilisable. Les noms varient selon l'outil : projet, espace, assistant. Vérifiez ce que propose votre abonnement. |
| Écran : un dossier avec trois documents : devis anonymisé, fiche attendue, gabarit vierge. | Que mettre dedans ? Peu de choses. Un exemple réel anonymisé, la sortie attendue pour cet exemple, le gabarit vierge. Pas tout le disque dur : un outil qui explore tous les dossiers peut se perdre. |
| Écran : le devis avec « client X1 » et « chantier X2 » à la place des noms. | Anonymisez les documents clients avant de les déposer. Remplacez les noms par des variables génériques. Nous reverrons les règles de confidentialité au module 7. |
| Écran : quatre blocs empilés : Rôle, Mission, Sources, Règles. | Les instructions tiennent en quatre blocs. Le rôle : qui est l'assistant. La mission : ce qu'il produit. Les sources : les seuls documents à utiliser. Les règles : n'invente rien, signale ce qui manque. |
| Écran : la demande C du module 2 qui se glisse dans les blocs. | Partez de votre demande C du module 2. Elle contient déjà presque tout. |
| Écran : un premier essai, des erreurs surlignées, une note « à corriger au module 6 ». | Lancez un premier essai. Notez ce qui fonctionne et ce qui ne va pas, sans corriger tout de suite. Au module 6, chaque erreur deviendra une règle. Consigne pour vous : créez votre projet, déposez votre exemple, écrivez vos instructions. |
