Question d'accroche : peut-on décrire un cas d'usage de façon claire en quatre cases seulement ?

| Ce qu'on voit | Ce qu'on dit |
|---|---|
| Écran : une grille vide de quatre cases, avec les lettres E, T, S, C. | Peut-on décrire un cas d'usage de façon claire en quatre cases seulement ? Oui. C'est la grille E-T-S-C : Entrée, Transformation, Sortie, Contrôle. |
| Écran : case E « Entrée » qui se remplit : « Le devis, les pièces complémentaires ». | Entrée : quelles données ou quels documents sont disponibles ? Dans notre exemple, le devis ou la commande, et d'éventuelles pièces en complément. |
| Écran : case T « Transformation » : « Identifier les lignes à produire et leurs caractéristiques ». | Transformation : que faut-il comprendre, extraire, comparer ou générer ? Ici, identifier les lignes à produire, avec leur essence, leur section, leur quantité. |
| Écran : case S « Sortie » : « Fiche de production standardisée ». | Sortie : quel résultat concret ? Une fiche de production standardisée, avec toujours les mêmes champs. |
| Écran : case C « Contrôle » mise en valeur : « Incohérences, dimensions, quantités, délais, informations manquantes ». | Contrôle : qu'est-ce qu'un humain doit impérativement vérifier ? Les incohérences, les dimensions, les quantités, les délais, ce qui manque. C'est la case la plus importante, et la plus oubliée. |
| Écran : trois lignes qui s'ajoutent sous la grille : utilisateur, test, exigence. | Ajoutez trois lignes. L'utilisateur : qui se sert de la sortie ? Le test : comment comparerez-vous le résultat à la bonne réponse, sur plusieurs documents ? L'exigence : par exemple, fonctionner sur un document jamais vu. |
| Écran : quatre mots multipliés : valeur, fréquence, faisabilité, contrôlabilité. | Reste à savoir si le cas vaut le coup. Quatre critères à multiplier : la valeur, la fréquence, la faisabilité, la contrôlabilité. Notez chacun de un à trois. |
| Écran : une calculatrice, un critère à 1 entouré en rouge. | Un seul critère à un tire le produit vers le bas. Une tâche rare, ou impossible à contrôler, ne mérite pas de prototype. Et la valeur reste une hypothèse tant que vous ne l'avez pas mesurée. |
| Écran : la fiche complète d'une page. | Consigne pour vous : remplissez la fiche E-T-S-C de votre cas fil rouge, sur une page. Elle sera la première page de votre projet final. |
